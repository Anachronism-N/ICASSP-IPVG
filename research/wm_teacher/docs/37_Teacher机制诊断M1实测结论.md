# 37 Teacher机制诊断M1：实测结论

> 2026-10-20。M1真实前向与独立复算完成；不是Teacher质量通过。固定5B，未训练Student/蒸馏/AR/FT3，未新增生成视频。

## 1. 执行和验收

固定P1六个训练可见案例、同校订dense label/原非空NEG/首帧与CPU fp32 seed0噪声。真实GT一次VAE编码，同三个native scheduler状态分别用于base/A07的正负分支。GT加噪前向过程不是模型rollout重放，不能从本诊断直接推断视频动作质量。

- 18共享状态、72单分支真实前向；两worker及CPU分析零退出，自有进程组完整回收。
- 实际两卡保守allocated成本 **0.182380 GPUh**，硬上限2；328.284289秒账本含最后write/exit保守1秒，不是kernel耗时。
- 233本地源码/框架快照hash、36 P1输入输出记录、226原框架、10本地模型cache和runner source最终SHA重验通过。
- 独立CPU加载全部真实tensor复算18组，比较 **54,378项数值，最大差0**。不重跑GPU。
- 正负分支使用同x_t/t/首帧；统计排锁定首latent，Zero投影k按完整张量含首latent归约。

A07正支raw MSE在18/18状态低于base。但正、负预测都变化，整体预测夹角平均约2.4–3.6°；两者之差p−n的方向变化55–64°，其相对位移约85.7%/98.0%/104.0%。因为p−n本来较小，相对指标容易大，不能单看这个比例下灾难性结论。

标准CFG `g_s=s*p+(1-s)*n`，更新差 `delta_g=s*delta_p+(1-s)*delta_n`。正负贡献含明显抵消/交叉项，独立验证AB/BA/AA−BB及均方恒等式，不能把RMS简单相加或归因于单负分支。

## 3. Zero投影支持程度

18状态×两模型的k范围 **[0.995319,1.000613]**，均接近1。CFG5下投影对guided RMS的最大相对改变base约1.70%、A07约0.81%，与原guided最大夹角约0.77°/0.87°。

因此本轮**没有观察到足以优先支撑“负分支标量幅值严重失配，靠Zero投影即可修复”的证据**。这不是证明Zero永远无效：本轮未覆盖模型真实rollout，未测首步index0；小变化多步积累也可能不同。但不应据论文名或空闲卡盲开更多Zero/APG网格。

## 4. 对当前退化的解释边界

**实测支持**：正caption训练/验证改善不保证完整CFG场与最终视频质量；小的正负预测变化可能导致p−n明显改变，损失与推理行为存在评价盲区。

**尚未证明**：本地这些GT forward states的预测方向差就是P1机器人失败的因果根因；NEG本来不对应正caption GT，因此不拿负MSE定义负文本能力；latent时间差不是光流/动作成功。

不能据此直接上线混合base正支/A07负支；AB/BA仅离线数学分解，没有生成质量验证。不能把更低正支MSE解释成“模型已超过SOTA”。

## 5. 下一步优先级

1. **完成随机标签语义审核**：L1已有17源340完整解码/抽样绑定，不是语义通过。固定每源最前入样窗的导航试审已发现具体朝向/动作终局/相机静止描述矛盾，但四窗稀疏审阅不估计总体错误率。全clip判定 supported/contradicted/unverifiable，保留不确定和抽样概率，不补易例。
2. **先保真单因素训练方案，不盲FT3**：语义审核支持后，用清洁子集、基座初始化、相同更新预算比较SFT与same5B预测保真；这是相关文献外推，不是本轮已经训练。先梯度/保存/恢复smoke，保持原dense-only、动作/画质/GT护栏。该训练仍须明确范围与预算，不能把Stop hook当Student蒸馏授权。
3. **推理改法后置**：若以后更贴近rollout或首步状态的限定测量支持，才冻结一个single-factor小试，标准CFG对照保留、12视频以内另预注册预算；不把projection+early zero同时变更称单因素。
4. **偏好优化再后置**：先检验综合reward是否偏选近静止或动作失败，参考冻结基座不能保证动作；不能用同reward筛样后再宣称泛化。
