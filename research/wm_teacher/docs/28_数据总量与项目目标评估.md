## 二、能否全部上传到 HuggingFace

### 结论：**不能全部上传，也不建议。**

### 2.1 已上传到 HF 的内容 ✅

仓库 `NZC415/wm-dataset`（私有）已包含：
- 统一 manifest（train 70,151 / val 7,783，JSONL + CSV）
- 11 个数据集的 `*_wan22/manifest_wan22.jsonl`
- 全部处理脚本（transcode_and_clip.py、build_unified_manifest.py 等）
- 训练配置（wan22_training_config.json、accelerate_config.yaml）
- 审计报告（decode_audit_report.json）
- 文档（数据集收集与许可、预处理方案）

**已上传总量：~120MB**

### 2.2 无法上传的原因

| 限制 | 说明 |
|------|------|
| **体积** | 已处理 clips ~5TB + 原始数据 ~24TB = ~29TB。HF LFS 存储和带宽成本极高 |
| **单文件** | HF LFS 单文件建议 <5GB；MIRA 单数据集 4TB |
| **许可** | 大部分数据集为研究许可，禁止再分发（即使私有仓库）|
| **实用性** | 29TB 上传/下载耗时极长，不如共享 FS + rsync |

### 2.3 建议的跨服务器同步策略

1. **Manifest + 脚本** → HF（已完成 ✅，~120MB）
2. **视频 clips** → 共享 FS（当前方案）或 rsync 到目标服务器
3. **模型权重** → ModelScope/HF 原始仓库下载（Wan2.2 已在 ModelScope）
4. **新服务器复现流程**：
   ```bash
   hf download NZC415/wm-dataset --repo-type dataset --local-dir wm_dataset_meta
   # 然后用 manifest 中的 video_path 从共享 FS 或原始来源获取视频
   ```

### 2.4 如确实需要上传部分视频到 HF

建议只上传小数据集（总计 <50GB）：
- H2O: 682MB
- OpenVidHD: 2.6GB
- DexYCB: 4.8GB
- EasyCom: 8.1GB
- NoXi: 71GB（偏大，可选）
- Matrix: 49GB（偏大，可选）

## 三、当前数据能否满足项目目标

### 3.1 项目目标回顾

> 构建以人为中心的全双工多模态交互世界模型，采用"VLM 大脑 + 视频 DiT 渲染器"分层架构。当前阶段：Wan2.2-TI2V-5B 作为视频生成 Teacher 的快速验证。

### 3.2 数据覆盖度评估

| 目标场景 | 已有数据集 | 覆盖度 | 缺口 |
|---------|-----------|--------|------|
| **手物交互** | DexYCB, H2O, HOIGen | ✅ 充分 | 无 |
| **日常居家活动** | Charades, EasyCom | ✅ 充分 | 无 |
| **多人对话/互动** | NoXi, Seamless | ✅ 充分 | 无 |
| **第一人称活动** | Ego-Exo4D, HoloAssist(待完成) | ⚠️ Ego-Exo4D 处理中 | HoloAssist 修复中 |
| **游戏场景** | MIRA(Rocket League), Matrix(Forza/Cyberpunk) | ✅ 充分 | 无 |
| **通用高清视频** | OpenVidHD | ⚠️ 仅抽样 1,317 clips | 可扩大抽样 |
| **数字人脸** | 无 | ❌ 缺失 | 需 CelebV-HQ/VFHQ（百度网盘） |
| **唇读音视频** | 无 | ❌ 缺失 | 需 LRS2/LRS3（BBC 协议） |

### 3.3 首轮训练目标评估

| 指标 | 目标 | 当前 | 评估 |
|------|------|------|------|
| 训练样本数 | 20K-50K | 70,151 train / 7,783 val | ✅ 超过目标 |
| 数据集多样性 | ≥5 个来源 | 11 个来源 | ✅ 充分 |
| 单一来源占比 | ≤50% | HOIGen 25.7% | ✅ 合规 |
| 视频格式 | 1280×704 24fps 4s | 全部符合 | ✅ |
| 路径完整性 | 100% | 0 缺失 | ✅ |
| Caption | 有 | MIRA 有，其余空 | ❌ 需 VLM 打标 |
| 首/尾帧条件 | 首帧可提取 | 100% 验证通过 | ✅ |

### 3.4 结论

**首轮训练：✅ 可以启动。**
- 数据量（70K train）远超目标（20K-50K）
- 11 个数据集覆盖了主要交互场景
- 唯一缺口是 caption——MIRA 已有，其余需等 8×H20 235B 打标
- 可先用 MIRA caption 做 smoke training 验证管线，其余 caption 到位后全量训练

**完整项目目标：⚠️ 基本满足，有缺口。**
- 缺数字人脸（CelebV-HQ/VFHQ）和唇读（LRS2/LRS3）数据
- HoloAssist 修复中（~33 天），Ego-Exo4D 处理中（~12h）
- Caption 是当前最大瓶颈——需 8×H20 集群部署 Qwen3-VL-235B
- OpenVidHD 仅抽样 1,317 clips，可按需扩大
