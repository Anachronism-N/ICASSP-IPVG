# 44 用户委托代审：17个试审窗口caption结论（2026-10-21）

> 用户无法访问审阅网页，委托助手代审。3个盲态助手各审一组（6/6/5例），互不重叠，均看不到此前任何结论。**这是助手审阅，不是人类gold。**17例是每个数据集冻结试审池的第一个样本，存在顺序偏差，不能当作整体错误率估计。

## 1. 结果

- 总体：**0例可直接用，10例需修改，7例不应使用**。17例全部有至少一处画面可见的矛盾。
- 分类（相符/矛盾/无法判断）：物体 4/13/0，动作 4/13/0，镜头 12/4/1，结束状态 5/9/3。**镜头描述基本可靠，物体与动作错误最多。**
- 所有“需修改/不应使用”的案例都附了只写可见内容的修正caption（私有保存）。

## 2. 主要错误类型

1. 凭空写出或认错物体：手里拿着的东西、家具、屏幕、桶里的东西（例如把蛇写成塑料袋）。
2. 动作臆造或方向写反：上楼写成下楼，切面团写成揉面团，机械臂提锅盖写成抓锅柄倒东西。
3. 写了画面里看不到的结束状态。
4. 游戏或渲染画面被描述成真实场景。
5. 人物属性错误，例如衣服颜色、朝向。

## 3. 与此前复核的一致性

- 与主流程17例试审：68项分类判定中42项一致，10项直接冲突（一方相符、一方矛盾），按案例“是否有可见矛盾”一致13/17。冲突多为代审判矛盾、主流程判相符或无法判断，代审更严格。
- 与4例盲审：16项中12项一致，1项直接冲突。
- 三方都认为原caption错误普遍，但对单个细节的判定有分歧，单个助手审阅不能当作逐条真值。

## 4. 对实验的影响

- 原caption不适合直接用于定向训练（docs/43 E3）。必须先用约束性提示词重标注：只描述可见内容，禁止写看不清的手持物体、未出现的动作和结束状态，并标明游戏/渲染画面。
- 重标注结果在训练对比前，要在新的随机样本上再审一次。
- E1推理配置消融不依赖caption质量结论（只比较采样配置，caption固定为原文），照常进行。
