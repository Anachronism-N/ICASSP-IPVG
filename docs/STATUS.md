## 接下来的执行顺序

1. 本人完成比赛与数据授权，确认 GPU 型号、可用时长和最终输出/外部资源细则。
2. 安装控制框架，运行 doctor 与合成 smoke，阅读所有命令的 `--help`。
3. 在服务器部署已提供的VACE adapter与固定commit上游，先完成单条真实生成。
4. 构建身份/源视频隔离的子集，完成单节点训练/恢复/回载 pilot。
5. 取得真实吞吐后冻结首轮预算与 proxy，再启动有限 campaign。
6. 每周根据同预算收益和剩余 primary 产能决定是否扩模型/数据/Track 2。
